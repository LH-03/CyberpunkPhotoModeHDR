# Contributing and bug reports

This repository is a source-available limited audit tree, not the complete
production build tree. Documentation, compatibility reports, reproducible bug
reports, and improvements to the public contracts are welcome for
noncommercial purposes under `LICENSE.md`.

## Useful bug report fields

- Cyberpunk 2077 store/build version;
- GPU model and driver version;
- Windows version and HDR configuration;
- active game resolution and HDR mode;
- raster, RT, path-tracing, DLSS/FSR/XeSS, frame-generation, and Ray
  Reconstruction settings;
- other graphics and Photo Mode mods;
- selected `mode` and `gallery` values;
- RED4ext plugin log, worker log, and crash ReportQueue path when applicable;
- one original native PNG and one affected Ultra HDR file when sharing them is
  acceptable.

Please describe the observed result and the expected result. “Photo looks
wrong” without the environment, files, or logs is usually not actionable.

## Scope boundary

The repository does not accept requests for private executable addresses,
signatures, D3D12 resource identities, shader captures, reverse-engineering
tooling, or the omitted production source. A public issue is not permission to
use the project commercially. See `SOURCE-AVAILABLE-NOTICE.md`.
