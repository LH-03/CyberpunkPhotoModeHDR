# Cyberpunk 2077 原生拍照模式 Ultra HDR v0.1

这是一个直接接入《Cyberpunk 2077》原生拍照模式的实验性 HDR MOD。
按的仍然是游戏自己的拍照键；MOD 不截桌面、不截交换链，也不依赖
Steam/NVIDIA/ReShade 截图。它在原生拍照任务完成后，从游戏 Photo Mode
内部当前分辨率 FP16 成片支路读取图像，生成普通软件也能降级显示、支持软件
可显示 HDR gain map 的 Ultra HDR JPEG。

## 它和其他 HDR/截图方案的边界

- 实时 HDR/色调映射 MOD 改变的是游玩时显示器收到的画面；
- Steam、驱动、Overlay、桌面或交换链截图工具保存的是最终显示输出；
- 本 MOD 监听游戏自己的 `TakeScreenshot_HiRes` 拍照动作，保留原生黑屏、
  通知和 PNG，再从 Photo Mode 内部无 UI、当前分辨率 FP16 支路生成 Ultra HDR。

这是架构上的区别，不代表所有其他 HDR MOD 都采用同一种方法，也不贬低优秀的
外挂 HDR 截图工具；它解决的是“2077 原生拍照模式保存文件”这一条链路。

## 首发版必须说明的限制

- 目前只在一台机器验证：Steam 2.31、RTX 5070 Laptop 8GB、HDR10 PQ。
  同一台机器上简单测试了多种分辨率、关闭光追和不同光追档位，均正常输出；
  这不代表其他硬件、驱动、MOD、路径追踪组合或未来版本一定兼容。
- “忠实”不是严格复刻屏幕，只是在参考设备上更接近游戏观感；“浓郁”是
  主动增强亮度、饱和度和暖色的风格。两种预设都会受纸白、峰值、显示设备、
  手机 HDR 增益和查看软件影响，不同设备看到差异属于预期。
- v0.1 只验证 HDR10 PQ，不支持声明 scRGB。
- 贴纸/相框尚未进入 HDR 输出；Gallery 替换默认关闭。

## 功能

- 游戏原生快门触发，保留原 PNG 和原生通知；
- HDR 输出跟随实际游戏捕获资源，本机实测 2560x1600；
- 忠实、浓郁、一次快门双输出；
- 动态读取本次运行时纸白与峰值；
- Ultra HDR JPEG：HDR 软件显示增益，普通 JPEG 软件显示 SDR fallback；
- 自适应等待游戏完成原生照片，避免误抓 DLSS/TAA/RR/PT 过渡帧；
- 可选 Gallery SDR 代理与原 PNG 可恢复备份。

## 前置与安装

唯一运行时前置：RED4ext。把压缩包内容解压到游戏根目录即可。
详细配置、输出目录、卸载和日志位置见包内 `README.zh-CN.md`。

## 为什么输出 Ultra HDR JPEG

目标不是说 JPEG 比所有 HDR 格式都高级，而是让同一文件跨设备更省事：支持
gain map 的手机/软件显示 HDR，不支持的软件仍把它当普通 JPEG 显示正确的 SDR
底图。相比之下，NVIDIA 的 JXR 更偏 Windows HDR 截屏工作流，手机通常需要额外
查看器或转换；Steam 的 HDR AVIF 压缩和高位深能力很好，但查看器/色彩管理支持
仍不完全一致（参考机曾在一个查看器中偏红，这不是 AVIF 格式本身必然错误）。
EXR 更适合后期母版但文件大且不适合日常分享，2077 原生 PNG 则保留 SDR、画册
和装饰兼容性。Ultra HDR 的缺点也明确：JPEG 与 gain map 有损，网站重压缩可能
剥离 HDR，最终观感仍受设备和查看器影响。包内 `FORMAT-CHOICE.md` 有完整对比。
