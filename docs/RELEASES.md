# Releases

Installable builds are distributed through GitHub Releases. A Nexus Mods page
may be added later, but it is not required to download or run the mod. The
GitHub repository contains only a limited source/audit subset and is not a
complete build tree.

For v0.1, download:

```text
CyberpunkPhotoModeHDR-v0.1-experimental.zip
```

Compare its SHA-256 value with `release-assets/SHA256SUMS.txt` before installing.
The checksum file is regenerated together with each binary release.
