# Conservative roadmap / 近期改进方向

v0.1 is an experimental first release. Near-term improvements under
consideration are deliberately limited to observed product issues:

- test more GPUs, resolutions, Windows/driver versions, and raster/RT/path-
  tracing combinations;
- add or improve scRGB handling if a reliable device-independent path is
  validated;
- carry Photo Mode stickers and frames into HDR output;
- improve Gallery refresh/cache behavior and decoration compatibility;
- make diagnostics and configuration errors easier to understand;
- reduce avoidable capture latency while keeping the temporal-history gate.

These are investigation targets, not promised features or release dates.
